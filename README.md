# HeritEon

Software for engineering, graphics and data processing.

HeritEon develops standalone applications, extensions for existing
software, and reusable libraries. Custom development sits alongside
independent work on algorithms and development tools.

## Areas of work

- **BIM and engineering** — application add-ons, workflow automation
  and data exchange.
- **Graphics and visualization** — tools for working with visual
  content and geometric data.
- **Image and data processing** — processing pipelines and software
  components.
- **Systems and networking** — integrations and tools for connected
  environments.
- **Algorithms and development tools** — performance-focused libraries
  and independent software research.
